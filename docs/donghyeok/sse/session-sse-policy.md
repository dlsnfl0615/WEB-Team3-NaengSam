# SSE·단일 로그인 세션 정책

[sse-current-behavior.md](sse-current-behavior.md)에서 정리한 "우선 결정 필요" 항목에 대한 결정.

## 로그인 세션

- 사용자당 활성 로그인 세션은 하나다.
- 새 로그인이 성공하면 같은 사용자의 기존 디바이스 세션은 강제 로그아웃된다.
- 같은 세션 안에서 여러 탭을 여는 것은 허용한다 (탭 복제·새로고침 포함).

## SSE 연결 관리

- SSE 연결은 `userId → connectionId` 목록으로 관리한다. 한 사용자가 여러 탭을 열면 여러 `connectionId`가 같은 `userId`에 매핑된다.
- 사용자당 SSE 연결은 최대 5개까지 허용한다. 초과 시 가장 오래된 연결을 정리한다.
- 로그아웃 또는 세션 만료 시 `disconnectAll(userId)`를 호출해 해당 사용자의 모든 emitter를 즉시 종료한다. 세션 단위가 아니라 사용자 단위로 정리하므로, 강제 로그아웃된 디바이스의 SSE도 함께 끊긴다.

## 후속 구현 대상

- 로그아웃/세션 만료 이벤트에 `disconnectAll(userId)` 연결
- 사용자당 연결 5개 제한 로직
- 새 로그인 시 기존 디바이스 세션 무효화 로직
