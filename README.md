# WEB-Team3-NaengSam

# 🤝 Ground Rules

프로젝트를 원활하게 진행하고 건강한 협업 문화를 만들기 위한 팀 규칙입니다.

---

## 💬 커뮤니케이션

### 기본 원칙

- **"해주세요" 금지**
  - 도움이 필요하다면 **근거, 방향성, 범위를 함께 설명하여 공유**한다.
  - 단순 요청보다 상황을 함께 전달하는 것을 원칙으로 한다.

- **개인 DM 금지**
  - 모든 업무 관련 대화는 **Slack 공개 채널**에서 진행한다.

- **답장은 반드시 하기**
  - 확인했다면 간단한 이모지나 한마디라도 남긴다.
  - 읽고 넘어가는 상황은 만들지 않는다.

- **못했으면 못했다고 공유하기**
  - 진행하지 못했다면 숨기지 않는다.
  - 아래 내용을 함께 공유한다.
    - 못한 이유
    - 어디에서 막혔는지
    - 도움이 필요한 부분

- **에어팟을 끼고 있어도 말 걸기**
  - 집중 중처럼 보여도 필요한 내용은 편하게 이야기한다.

---

## 💻 개발 문화

- **커밋과 PR은 반드시 남기기**
  - 팀에서 정한 **Commit Convention**을 따른다.
  - 작업 내용이 드러나도록 PR을 작성한다.

---

## 🤝 회의 문화

- **회의 중에는 딴짓하지 않기**
  - 회의에 집중하고 적극적으로 참여한다.

- **회의에서는 존댓말 사용**

- **반론이나 반대 의견이 있을 때**
  - `"2얏!"`을 외치며 손을 든다.
  - 이후에는 **용용체**로 의견을 제시한다.
  - 논의가 길어지기 전에 의견을 명확하게 전달하는 것을 목표로 한다.
